# CS302 Operating Systems

## Course overview
CS302 is a 4-credit course with 3 credits of theory and 1 credit of laboratory work. The prerequisite is Computer Organization.

## Units
Unit 1 covers processes, threads and system calls. Unit 2 covers CPU scheduling algorithms. Unit 3 covers process synchronization, semaphores and deadlocks. Unit 4 covers memory management, paging and virtual memory. Unit 5 covers file systems, disk scheduling and protection.

## Textbooks and references
The main textbook is Operating System Concepts by Silberschatz, Galvin and Gagne. Modern Operating Systems by Tanenbaum is a reference book.

## Laboratory
The laboratory is conducted on Linux and covers shell scripting and system calls written in C.
