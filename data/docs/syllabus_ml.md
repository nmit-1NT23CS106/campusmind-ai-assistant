# CS303 Machine Learning

## Course overview
CS303 is a 3-credit theory course. The prerequisites are Linear Algebra, Probability and Statistics, and programming in Python.

## Units
Unit 1 covers the basics of machine learning and linear regression. Unit 2 covers classification with logistic regression, support vector machines and decision trees. Unit 3 covers model evaluation, the bias-variance trade-off and regularization. Unit 4 covers unsupervised learning with k-means clustering and PCA. Unit 5 introduces neural networks.

## Textbooks and references
The main textbook is Introduction to Machine Learning by Ethem Alpaydin. Hands-On Machine Learning by Aurelien Geron is recommended for practice.

## Assessment
Instead of assignments, the 10 internal assignment marks are awarded for a mini project in which students train and evaluate a model on a dataset of their choice.
