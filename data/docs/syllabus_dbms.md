# CS301 Database Management Systems

## Course overview
CS301 is a 4-credit course with 3 credits of theory and 1 credit of laboratory work. The prerequisite is Data Structures.

## Units
Unit 1 covers database concepts and entity-relationship modelling. Unit 2 covers the relational model, relational algebra and SQL. Unit 3 covers functional dependencies and normalization up to BCNF. Unit 4 covers transactions, ACID properties, two-phase locking and deadlocks. Unit 5 covers file organization, B+ tree indexing, query processing and an introduction to NoSQL.

## Textbooks and references
The main textbook is Database System Concepts by Silberschatz, Korth and Sudarshan. A reference book is Fundamentals of Database Systems by Elmasri and Navathe.

## Laboratory
The laboratory uses MySQL and includes a mini project in which students design a database for a real-world scenario.
